# ラッシュアワー - Rush Hour Master (Webアプリ)

混雑した駐車場から「赤い車」を脱出させる大人気スライディングブロックパズルです！

---

## 🎮 起動方法

### 最も簡単な方法（ダブルクリック）
`index.html` ファイルをブラウザ（Google Chrome, Edge, Safari など）にドラッグ＆ドロップするか、ダブルクリックして開くだけで即座に遊べます。

---

## 🚗 ルール & 目的

- **目的**: 駐車場中央の出口（EXITゲート）から、**赤い車（マイカー）**を外へ脱出させましょう！
- **車の動かし方**:
  - **横向きの車**: 左右にのみスライドできます。
  - **縦向きの車・トラック**: 上下にのみスライドできます。
  - 他の車や壁を飛び越えることはできません。
- **クリア判定**:
  - 邪魔な車を前後にスライドさせて道をあけ、赤い車を右端の出口へスライドさせると脱出成功です！

---

## ✨ 主な機能

1. **直感的なドラッグ＆フリック操作**:
   - マウスでのドラッグはもちろん、スマートフォンやタブレットのタッチスワイプ（フリック操作）にも完全対応。指先で気持ちよく車をスライドできます。
2. **三ツ星（★★★）評価システム**:
   - 最短手数でクリアすると最高ランクの「★★★」を獲得！
3. **BFS最短手数ソルバー & ヒント機能**:
   - 行き詰まったときは「ヒント」ボタンを押すと、次の一手で動かすべき車が青く光ってナビゲートしてくれます。
4. **1手戻す（Undo） & リセット**:
   - 失敗しても何度でも手戻り・再挑戦できます。
5. **ダイナミックな脱出演出**:
   - クリア時には赤い車が勢いよく出口から走り去り、紙吹雪でお祝いします！

---

## ⌨️ キーボードショートカット（PC向け）

| キー | 動作 |
|---|---|
| `Ctrl + Z` | 1手戻す（Undo） |
| `R` | ステージをリセット（最初からやり直す） |
| `H` | 次の一手ヒントを表示 |

---

## 🛠 技術仕様

- **HTML5 / CSS3 / Vanilla JavaScript (ES6+)**
- **幅優先探索（BFS）アルゴリズム**: 最短手数の自動計算およびヒント提示エンジン
- 外部通信・外部ライブラリ依存ゼロ（完全オフラインで動作可能）
