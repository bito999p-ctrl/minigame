# ナンプレ - Sudoku Master (Webアプリ)

ブラウザで快適・爽快に遊べるモダンな数独（ナンプレ）Webアプリケーションです。

---

## 🎮 起動方法

### 最も簡単な方法（ダブルクリック）
`index.html` ファイルをお好きなブラウザ（Google Chrome, Edge, Safari など）にドラッグ＆ドロップするか、ダブルクリックして開くだけで即座に遊べます。

### ローカルサーバーで起動する場合
Python がインストールされている場合、プロジェクトフォルダで以下を実行して起動することも可能です：
```bash
python -m http.server 8000
```
その後、ブラウザで `http://localhost:8000` にアクセスしてください。

## ✨ 主な機能

- **4段階の難易度**:
  - 初級（サクサク解きたい方向け）
  - 中級（程よい歯ごたえ）
  - 上級（論理的思考が必要な骨太パズル）
  - エキスパート（難問にじっくり挑みたい方向け）
- **自動パズル生成 & 一意解保証**:
  - 毎回ランダムに生成され、必ず答えが1つになるように設計された本格仕様。
- **メモ（鉛筆）機能**:
  - 1マスに複数の候補数字を小さく書き留めることができます。
  - 数字を本入力すると、同列・同行・同ブロックの同じメモが自動削除されます。
- **ハイライト＆アシスト**:
  - 選択中のマスと連動して、行・列・3x3ブロック、および同じ数字のマスが淡くハイライト。
  - ルール違反（同ブロック等での数字重複）を赤色で検知。
- **アンドゥ & リドゥ**:
  - 何手でも元に戻したりやり直したり可能。
- **ヒント機能**:
  - 行き詰まった際に、選択中または未入力/誤りのマスを1マス正解で埋めます。
- **スマホ・タブレット完全対応**:
  - レスポンシブ設計で、タップしやすいテンキーUIを完備。
- **クリア時の紙吹雪演出**:
  - 完成時にはタイムと難易度が表示され、鮮やかな紙吹雪が舞います。

## ⌨️ キーボード操作（PC向け）

| キー | 動作 |
|---|---|
| `1` 〜 `9` | 数字の入力（またはメモ書き） |
| `Backspace` / `Delete` | 選択中のマスの数字・メモを消去 |
| `↑` `↓` `←` `→` (矢印キー) | マスの選択移動 |
| `P` | メモ（鉛筆）モードの切り替え |
| `H` | ヒントを使用 |
| `Ctrl + Z` | 元に戻す（Undo） |
| `Ctrl + Y` または `Ctrl + Shift + Z` | やり直す（Redo） |

## 🛠 技術構成

- **HTML5 / CSS3**: CSS Grid, Flexbox, CSS Variables, レスポンシブUI
- **Vanilla JavaScript (ES6+)**: バックトラッキング法による数独ソルバー＆ジェネレータ、Canvas APIによる軽量紙吹雪演出
- 外部ライブラリへの依存なし（完全オフラインで動作可能）
